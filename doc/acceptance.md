# 首版验收记录

## 已执行

- `cargo test --offline`：29 项单元/Mock 测试通过，0 失败。
- `cargo clippy --offline --all-targets -- -D warnings`：通过。
- `cargo fmt --check`：通过。
- `cargo build --offline`：Windows debug 构建通过。
- CLI 真正运行：`--version`、`--help`、带空格根路径 `init`、重复 `init` 保留已有配置、`status` 返回 3、`stop` 返回成功、空凭据 `check` 返回 1。
- 部署脚本与打包脚本通过 `sh -n` / `bash -n`；在 Git Bash 明确拒绝非 Linux 部署，不把 Windows 程序打成 Linux 发布包。

依赖缓存、构建文件、测试夹具和 CLI 测试目录均在仓库 `tmp/` / `target/` 内。未提交或推送 Git。

## 已修复的自审问题

1. Windows 路径前缀逐级检查引起错误，修正后路径/配置/规则测试通过。
2. 非法极值群 ID 触发上游整数溢出，改为先验证范围。
3. 容量为 1 的发送队列被控制消息预留永久占满，修正预留上限并添加测试。
4. 两个限流响应可能将全局冷却时间缩短，改为取最大截止时间并添加 Mock 测试。
5. 重复运行实例在拿锁前开启共享日志，改为先拿锁再初始化日志。
6. RPC 外层取消可能让底层请求继续积压，增加取消即关闭连接的保护。

## 尚未验收 / 已知限制

- 真实账号登录、2FA、目标超级群更新、两段原生转发、媒体转发、客户端原文跳转及通知表现：无凭据，未执行。
- Linux 安装、启动/停止、迁移、权限与目录外写入追踪：未在 Linux 实机执行。当前仅 Windows CLI 行为与 shell 语法已验证。

- 部署安装器只支持新安装和同包幂等；自动升级、自动备份及回滚未实现，明确拒绝不同版本直接覆盖。

- 不能保证零丢失或 exactly-once；超载、未知发送结果、连接重建会产生漏提醒，已完成的转发阶段不盲目重发。
