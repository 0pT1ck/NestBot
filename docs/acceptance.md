## 真实链路验收

以下必须使用测试账号/目标在 Linux VPS 实测，自动化离线测试不能证明已通过：

1. 主账号/上传账号、二步验证、SOCKS5、重连和 DC 迁移。
2. 搜索占位消息编辑、排序、原消息续搜、重新定位、限流。
3. 分批领取的最后一组、按钮原地编辑、“全部获取”、未知文件数量；主账号受限后切换第二账号、第二账号受限后切回主账号、部分媒体转存后重取去重。
4. 单账号和双账号引用复制、相册和文件引用过期。
5. 图片、视频、音频、语音、大文件下载上传及停止。
6. 转发媒体的 copy 和 deep 回读、标签编辑权限。
7. 网络断开、磁盘不足、任务中 kill、发送成功但本地未落账。
8. 0.5 CPU/1GB cgroup 下 72 小时稳定性、RSS/cgroup 内存和传输速度。

## 当前边界

- MTProto 原生代理仅支持 SOCKS5，旧版 SOCKS4/HTTP 代理需要换 SOCKS5 入口。
- 账号登录通过 CLI；Web 负责日常管理。
- deep 转存逐文件发送，相册外观可能拆开；Bot API copy 聚合相册。
- 重传保留说明、文件名、非贴纸文档属性及可读取的小缩略图；实际媒体显示仍需真实链路验证。
- 取消仅保证停止本地继续调度；已经发出的远端请求可能仍完成。发送意图未核对时进入 review。
- 没有单文件字节级续传、密码更换及旧转存记录手动映射命令。
- `/log` 与 Web 运行记录显示任务事件摘要；单目录后台模式的完整诊断日志在 `.local/log/nestbot.log`，前台模式输出到标准输出。
